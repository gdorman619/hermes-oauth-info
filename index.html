Hermes personal assistant

Hermes is a personal-use assistant for email, calendar events, files, spreadsheets, and tasks. An optional read-only Oura connection supports personal fitness coaching. This website explains its Google and Oura permissions and privacy practices. It is not a public sign-in or an entry point to the assistant.

What it does

With the owner's permission, the assistant reads Gmail to find and summarize messages; works with Google Calendar to view and manage events; uses Google Drive to find and manage files; uses Google Sheets to read and update spreadsheets; and uses Google Tasks to organize to-dos. Operations that change external data are subject to the owner's instructions and confirmation.

Oura fitness coaching

With the owner’s authorization, the fitness assistant reads daily sleep, activity, and readiness summaries using only Oura’s daily permission. It combines trends with the owner’s existing workout log to offer practical coaching in the owner-selected messaging topic. It does not request Oura workout, heart-rate time-series, email, or personal-information permissions, and does not change Oura records. A single score is not a mandatory train-or-rest decision. This is general wellness guidance, not medical care.

Private access

The assistant is not available through this public site. The site contains no Google account content, credentials, or interactive assistant access.
